# Windows 使用说明

1. 下载对应版本的便携 EXE，或完整解压程序 ZIP 后运行其中的 MH.exe。
2. 使用分配的 Pro Server 普通账号登录。
3. 在“我的 Mac”中选择设备，点击“连接 Mac”。
4. 出现 Password required 时填写该设备的远控密码。
5. 如 Mac 显示锁屏或登录画面，选择分配的本地账户，填写该账户密码；出现桌面后开始操作。
6. 保存工作后，通过远控工具栏的关闭按钮断开连接。

当前测试包未签名；运行遇到系统拦截时向提供者核对文件来源和校验值。完整目录版的 DLL 和 data 目录须一起保留，便携 EXE 已封装这些文件。

服务器地址可在“设置 → 网络”调整。旧临时入口停用时，账号密码正确也无法连接；需要提供者给出有效服务配置。

连接失败时，区分账号登录失败、设备离线、中继连接失败与设备密码错误，并提供错误截图、发生时间和网络类型。反馈内容避开密码。设备列表出现不等于设备正在在线。

新版本采用新文件夹保存；回退时退出当前客户端并打开旧版本。此便携路线没有自动升级、安装服务或卸载流程的验收结论。
