# MH 1.5.1-mh.5-controller-test

开发预览，目标平台为 Windows x64。

## 功能

- MH 品牌、灰度界面和独立 MH Test 配置。
- Pro Server 账号登录、可访问 Mac 列表及连接按钮。
- 保留网络设置和设备密码认证。
- Windows WSS 控制端使用配置的公网中继地址，避免误用被控端返回的 LAN 地址。

## 分发限制

该预览的默认连接参数依赖已失效的测试入口，程序未签名。历史 EXE、程序 ZIP 和源码 ZIP 仅作版本追溯，不作为通用公开下载。源码 ZIP 包含构建时的公开连接配置；该配置不含账号密码，但仍需在发布附件前审阅。

公开分发应使用经过审阅的有效配置重新构建新版本，并验证目标网络上的登录、画面、输入及重连。macOS、Android 和 iOS 的 MH 变体不在本版支持范围内。

## English

Windows x64 development preview with MH branding, isolated configuration, account login, accessible Mac list and configured WSS relay selection. The historical binary depends on an expired test endpoint and is unsigned. Its source archive includes the build-time public connection profile. These artifacts are retained for version traceability, not offered as a general-purpose public download. Build and validate a new version with reviewed configuration before distribution; other MH platforms are not supported by this preview.
