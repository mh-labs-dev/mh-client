# MH desktop preview

Desktop controller preview based on RustDesk 1.5.1.

- Account login, assigned Mac list and remote connection controls.
- Fixed MH service defaults with editable network settings.
- Build-path privacy checks for desktop packages.

## Download

- **Windows x64:** download `MH-1.5.1-mh.12-preview-windows-x64.exe` and double-click it.
- **macOS Apple silicon:** download `MH-1.5.1-mh.11-privacy-test-macos-arm64.dmg`, open it and copy MH to Applications.

The applications include the AGPL-3.0 license. [Desktop build source](https://github.com/mh-labs-dev/mh-client/tree/4c32cf80d9f22b801c39ad50cfbac1a66fb7e5eb). Clone with `--recurse-submodules` and follow the platform build instructions.

Windows is unsigned; macOS uses ad-hoc signing without notarization. Access requires an assigned account and an available Mac. Existing network settings remain in effect after upgrading.
