# MH 1.5.1-mh.10-preview

Windows x64 preview based on RustDesk 1.5.1.

- Fixed MH service address and secure WebSocket defaults.
- Account login, assigned Mac list and remote connection controls.
- Editable network settings and standard device-password authentication.

## Download

Download `MH-1.5.1-mh.10-preview-windows-x64.exe` and double-click it. The portable executable includes the application and AGPL-3.0 license.

[Corresponding source](https://github.com/mh-labs-dev/mh-client/tree/v1.5.1-mh.10-preview). Clone this tag with `--recurse-submodules` and follow the README build steps.

The Windows application is unsigned. Existing network settings remain in effect after upgrading. Access requires an assigned account and an available Mac; this preview does not guarantee mainland China connectivity.
